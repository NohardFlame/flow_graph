# Известные проблемы

## ⚠️ КРИТИЧЕСКИЕ ПРОБЛЕМЫ

### 1. **Импакт-тестирование работает неправильно**
**Проблема:** Кнопка "Импакт тестирование" должна находить "все действия в которых есть выделенные действия", но работает как обычное тестирование для выделенных действий.

**Что должно быть:**
- Находить все действия, которые используют те же состояния (init_states/final_states), что и выделенные действия
- Генерировать тесты для всей связанной группы действий

**Что сейчас:**
- Генерирует тесты только для выделенных действий
- Не ищет связанные действия

**Решение требуется:** Реализовать поиск связанных действий через общие состояния в графе.

## 🐛 МЕНЬШИЕ ПРОБЛЕМЫ

### 2. **Кэширование старых версий script.js**
**Проблема:** Браузеры могут кэшировать старые версии script.js

**Решение:** При каждом обновлении нужно менять версию в index.html: `script.js?v=X`

### 3. **Отсутствие выделенных действий**
**Проблема:** При нажатии кнопок, требующих выделенных действий, без выделения - не всегда понятное сообщение

**Решение:** Улучшить сообщения об ошибках
